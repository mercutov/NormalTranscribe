Нормальный транскрайб
Портативная расшифровка роликов. Установка приложения не нужна.
Нужна видеокарта NVIDIA от 8 ГБ.

Важно
  Папка должна лежать по пути без кириллицы.
  Правильно: D:\NormalTranscribe
  Нельзя: путь с кириллицей (ломается GigaAM)

Как отдать коллеге
  1. Скопируй всю папку D:\NormalTranscribe целиком (exe, bin, pipeline, runtime).
  2. Отдельно: установи Ollama (https://ollama.com) и скачай модель.
     В окне приложения — выпадающий список моделей Ollama (кнопка «Обновить»).
     Рекомендации:
       • 8 ГБ VRAM:  ollama pull qwen2.5:7b-instruct   (~5–6 ГБ)
       • 12+ ГБ:     ollama pull qwen2.5:14b-instruct  (~9–11 ГБ)
       • 16–24 ГБ:   qwen3.5:27b и крупнее             (~16+ ГБ)
     ASR и LLM идут по очереди (не одновременно). Без Ollama расшифровка
     всё равно работает — конфликты останутся в «К сверке».

Как пользоваться
  1. Запусти «Нормальный транскрайб.exe» или bat с тем же именем
  2. Добавь ролики
  3. По желанию включи/выключи сверку через Ollama и выбери модель
  4. Нажми «Начать расшифровку»
  5. Программа сама найдёт голоса; окно спросит имена.
     Лайф / врезка — кнопка «no name» (в сводную не попадёт).
  6. Открой папку «Заметки» (отдельный Obsidian vault)

В «Заметки» только .md и папка .obsidian.
Кэш и имена спикеров — в runtime\work, не в vault.

Как устроена сверка
  1. GigaAM + Whisper + разметка спикеров
  2. Правила отсекают мелкие отличия
  3. Если Ollama запущена — она правит только сильные конфликты
  4. После сверки модель Ollama выгружается из VRAM (не висит часами)
  5. Остальное попадает в «К сверке»

Таймкоды в сводной: **00:00:00:00**, шаг 1 минута.

Обновления
  При старте приложение спрашивает GitHub Releases (если в update.json
  указан реальный github_repo). Runtime и Заметки при обновлении не трогаются.
  Сборка релиза для тестеров: Собрать релиз.ps1

В сводной: **Имя.** реплика.
На каждый ролик три md: сводная и два черновика. Править сводную.
