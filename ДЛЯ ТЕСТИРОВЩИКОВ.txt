Нормальный транскрайб — как установить
=====================================

Что это
  Программа расшифровывает ролики (два движка + спикеры) и кладёт заметки в Obsidian.
  Нужна видеокарта NVIDIA от 8 ГБ.
  Папка установки — только латиница (F:\NormalTranscribe — ок, D:\Расшифровка — нельзя).

-------------------------------------
УСТАНОВКА (один раз)
-------------------------------------

1. Открой PowerShell (Win+X → «Терминал» / Windows PowerShell).

2. Скопируй и выполни ОДНУ команду:

   irm https://raw.githubusercontent.com/mercutov/NormalTranscribe/master/install.ps1 | iex

3. Скрипт сам:
   - скачает программу и модели с GitHub (~8 ГБ, подожди);
   - поставит в F:\NormalTranscribe (если есть диск F),
     иначе в C:\NormalTranscribe.

   Другой диск — сначала так:
   $env:NT_HOME = "D:\NormalTranscribe"
   затем снова команду из пункта 2.

4. Когда спросит «Запустить сейчас?» — можно y.

5. Или вручную открой:
   F:\NormalTranscribe\Нормальный транскрайб.exe

-------------------------------------
OLLAMA (по желанию, для умной сверки)
-------------------------------------

1. Поставь https://ollama.com
2. В PowerShell:  ollama pull qwen2.5:7b-instruct
3. В окне программы включи «Сверка через Ollama» и выбери модель.

Без Ollama расшифровка тоже работает.

-------------------------------------
КАК ПОЛЬЗОВАТЬСЯ
-------------------------------------

1. Запусти exe.
2. Добавь ролики.
3. Нажми «Начать расшифровку».
4. Подпиши имена голосов (лайф/врезка — «no name»).
5. Открой папку «Заметки» в Obsidian.

-------------------------------------
ОБНОВЛЕНИЯ
-------------------------------------

При запуске, если вышла новая версия, программа сама спросит
«Скачать и установить?». Модели и твои Заметки не сотрёт.

Переустанавливать команду из пункта 2 каждый раз не нужно.

-------------------------------------
ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
-------------------------------------

- Политика выполнения скриптов:
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

- «Путь с кириллицей» — поставь в F:\ или D:\NormalTranscribe.

- Нет NVIDIA / мало памяти — на этой машине не поедет.
